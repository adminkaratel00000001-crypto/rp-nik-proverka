# Проверка РП-ника

Страница, которая сама проверяет, похож ли ник на РП-ник формата `Имя_Фамилия`.
Работает полностью в браузере, без сервера.

## Структура

```
index.html        страница
css/style.css     оформление
js/data.js        словари имён, фамилий и запрещённых слов
js/checker.js     логика проверки
js/app.js         интерфейс и события
```

## Публикация на GitHub Pages

1. Создайте репозиторий и загрузите все файлы с сохранением папок.
2. Settings → Pages → Deploy from a branch → `main` / `(root)` → Save.
3. Сайт откроется по адресу `https://<ваш-ник>.github.io/<репозиторий>/`.
